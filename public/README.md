# 🏋️ FitLog — Workout Library

FitLog is a modern and responsive workout library built with Next.js. It allows users to explore different exercises, view detailed workout information, create a daily workout plan, and save exercises for later.

## 🚀 Technologies Used

* **Next.js** — App Router and page navigation
* **React** — Building reusable UI components
* **TypeScript** — Type-safe development
* **Tailwind CSS** — Responsive and modern styling
* **DaisyUI** — UI components
* **React Toastify** — Toast notifications
* **Context API** — Managing plan and saved workout state

## ✨ Key Features

### 1. 🏋️ Workout Library

Browse all available workouts with their image, muscle groups, equipment, duration, calories, and rating.

### 2. 📋 Today's Workout Plan

Add exercises to today's workout plan and track the total number of exercises, minutes, and calories.

### 3. 💾 Save Workouts

Save your favorite workouts for later and manage them from the Saved tab.

### 4. 🔎 Workout Details

View complete workout information including equipment, difficulty, sets, reps, duration, calories, rating, and step-by-step instructions.

### 5. 📱 Responsive Design

The entire application is responsive and works across mobile, tablet, and desktop screen sizes.

## 📌 Additional Features

* Sort workouts by duration, calories, or rating
* View workout details from any workout card
* Remove workouts from the plan or saved list
* Toast notifications for user actions
* Empty state when no workouts are available
* Custom 404 page
* Loading state while fetching workout data

## 🎯 Project Goal

The goal of FitLog is to provide a simple and modern workout tracking experience where users can discover exercises, organize their daily workouts, and keep track of their fitness activities.
